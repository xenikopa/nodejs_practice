# Event / EventEmitter

## Задание

### Таймер

Создайте таймер, который будет генерировать событие tick и выводить сообщение в консоль.
Используйте EventEmmiter.

**Реализация**

Создан модуль `timer.js` с реализацией класса `Timer`. В классе реализованы:
- внутренний счетчик вызовов `emit`. Инкриментируется каждый вызов. 
- функция `sleep` для остановки выполнения `emit`. Возвращает функцию для возобновления работы `emit`
- функция `wakeUp` - возобновление функциональности `emit`. Входящий параметр `emitFunc` для обратного присваивания
- функция `checkProceed` - опрос пользователя в консоли о продолжении работы таймера. Входящий параметр `handler` для обработки ответа пользователя. 

Для вызова скрипта используется команда `node timer.js`. Каждые 5 секунд происходит опрос о продолжении работы программы. 

### Таймер

Создайте программу, которая выводит сообщения.
Пользователи смогут отправлять сообщения с помощью функции sendMessage, а функция receiveMessage будет получать и отображать эти сообщения.
sendMessage принимает два параметра username и message

**Реализация**

Создан модуль `messanger.js` с реализацией класса `Messanger`, который наследует `EventEmitter`. 

В модуле реализованы:
- функция `sendMessage` 
- функция `receiveMessage` 
- слушатель `onSendMessage`

Для вызова скрипта используется команда `node messanger.js`.
