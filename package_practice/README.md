# REPL / Module / Package

## Задание

Создать пакет, который возвращает функцию
Импорт работает CommonJS и ESModule

Эта функция
на вход принимает объект такого вида
```
{
  name: 'иван иванов'
  dateBirth: 10.11.1987,
  purpose: 'карьерный рост'
}
```

возвращает
```
{
  id: 'sdf3234gt4', // случайны id из 10 символов 
  firstName: 'Иван', // первая буква большая, остальные строчные
  lastName: 'Иванов', // первая буква большая, остальные строчные
  dateBirth: 10.11.1987,
  age: '35', // высчитывается возраст на текущий день
  purpose: 'Карьерный рост', // первая буква большая, остальные строчные
}
```
результат выводить в консоль

## Реализация

Название пакета `user-package`. Пакет содержит одну функцию `createUser`, которая принимает на вход объект. Поддержка экспорта CommonJs, ESModule. 

Пример вызова: 
```
import createUser from "user-package";
// const createUser = require('user-package');

const user = createUser({
 name: 'иван иванов',
 dateBirth: '10.11.1987',
 purpose: 'карьерный рост',
});
```

### Описание файлов

- `package.json` - описание пакета
- `main.js` - точка входа пакета модуль CommonJS. Экспортирует модуль userModule 
- `main.mjs` - оточка входа пакета модуль ESModule. Экспортирует модуль userModule 
- `userModule.mjs` - реализация функции `createUser` для преобразования объекта. 
- `helpers` - директория со вспомогательными функциями для работы с полями объекта
- `helpers/calcAge.mjs` - модуль расчета возраста на текущий день
- `helpers/generateId.mjs` - модуль генерации id из 10 случайных символов
- `helpers/logError.mjs` - модуль вывода универсального вида ошибки
- `helpers/mapString.mjs` - модуль преобразования строк. На данный момент реализует преобразование первого символа в upperCase.
